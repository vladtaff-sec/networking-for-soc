# Мережі для кібербезпеки

Інтерактивна презентація-повторення з мережевих основ для аналітика SOC Level 1 — підготовка до сертифікації TryHackMe SAL1 та технічних співбесід.

**Дивитись:** https://vladtaff-pro.github.io/networking-for-soc/

## Що всередині

25 слайдів з горизонтальною навігацією, які покривають:

**Фундамент** — модель OSI з прив'язкою атак до кожного рівня, стек TCP/IP та інкапсуляція, порівняння TCP і UDP, three-way handshake і прапорці TCP, різниця між станами портів open / closed / filtered.

**Адресація** — приватні діапазони RFC 1918, субнетинг і повна таблиця CIDR, спеціальні адреси, TTL і принцип роботи traceroute, таблиця портів, які аналітик має знати напам'ять.

**Протоколи** — ARP та ARP spoofing, DHCP і процес DORA, NAT, робота DNS і типи записів, використання DNS в атаках: тунелювання, DGA, fast flux.

**Веб і шифрування** — повний шлях запиту від введення URL до відрендереної сторінки, TLS handshake, ланцюжок довіри та перевірка сертифікатів.

**Інструменти** — мережеві пристрої, різниця IDS та IPS, фільтри Wireshark, tcpdump і Nmap з погляду синьої команди.

**SOC-практика** — як типові атаки виглядають у мережевому трафіку, джерела мережевих логів для SIEM, підсумкова шпаргалка і план повторення.

## Технічно

Один самодостатній HTML-файл без залежностей і зовнішніх запитів. Навігація стрілками, свайпом або через точки внизу. Адаптовано під мобільні пристрої.
